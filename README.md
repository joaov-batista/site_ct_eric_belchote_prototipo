# 🏐 Website CT Eric Belchote

Um website institucional estático e totalmente responsivo para o CT Eric Belchote, uma escola de vôlei de praia. O projeto foi desenvolvido para apresentar as unidades da escola, seus horários e facilitar o processo de matrícula de novos alunos de forma direta e eficiente.

## ✨ Funcionalidades Principais

* **📖 Páginas Informativas:** Estrutura multi-página (`Home`, `Unidade Stella Maris`, `Unidade Piatã`, `Matrícula`) para organizar e apresentar as informações de forma clara e acessível.

* **📱 Design Totalmente Responsivo:** A interface se adapta perfeitamente a qualquer dispositivo, seja desktop, tablet ou celular, garantindo uma ótima experiência de usuário em todas as telas.

* **🖼️ Carrosséis de Imagens Dinâmicos:** Múltiplos carrosséis de imagens controlados por JavaScript para exibir fotos da escola e das unidades de forma atraente e profissional, com navegação manual e automática.

* **📝 Formulário de Matrícula Inteligente:**
    * Filtra dinamicamente as turmas disponíveis com base na unidade selecionada pelo usuário.
    * Ao preencher o formulário, um link para o **WhatsApp é gerado com uma mensagem pré-formatada**, contendo todos os dados do aluno e as turmas escolhidas. Uma solução eficaz para captar leads sem a necessidade de um backend.

* **✨ Animações e Transições Modernas:** O site utiliza animações sutis em CSS (`@keyframes`) para criar uma navegação mais fluida e uma experiência visual mais agradável.

* **🚀 Otimizado para SEO:** O código inclui meta tags essenciais (`description`, `keywords`), uma tag `canonical` e um arquivo `sitemap.xml` para melhor indexação nos motores de busca.

---

## 💻 Tecnologias Utilizadas

Este é um projeto puramente **frontend**, sem a necessidade de um backend ou banco de dados.

* **Estrutura e Estilo:** `HTML5` e `CSS3` (utilizando Flexbox, Grid e animações).
* **Interatividade:** `JavaScript (Vanilla)` para manipular o DOM (menu mobile, carrosséis e o formulário de matrícula).
* **Ícones:** `Font Awesome`.
